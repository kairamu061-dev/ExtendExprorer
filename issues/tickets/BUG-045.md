# BUG-045: 届かないパスがあると、見ているフォルダのアイコンが約 42 秒出ない

- **State**: Open
- **Reported**: 2026-10-04（動作確認フィードバックで発見。**依頼書に無い項目**）
- **Area**: shell-icons（`Services/ShellImageList.cs`）

## Summary

アイコンを**裏で引くスレッドが 1 本**しかないので、
**届かないパスの取得がその 1 本を握る**と、
**手前のタブ（見ているフォルダ）の絵が、試行が諦めるまで出ない。**

**UI は固まらない**（往復は最大 1〜3ms・タイムアウト 0）。**待たされるのは絵だけ。**

## Reproduction

届かない UNC のタブを含む session で起動し、手前のタブを**冷えた `.exe` フォルダ**にする。

```
1 回目: ink 188 のまま t=939ms 〜 41,833ms（接続試行が開いている間）
        → t=42,733ms で 202、t=45,571ms で 247   （試行が終わった直後）
2 回目: ink 201 のまま t=873ms 〜 41,691ms
        → t=44,427ms で 204、t=47,236ms で 225

対照（同種の冷えたフォルダ・届かないタブ無し）:
        ink 288 が t=797ms で出て、以後そのまま
```

**2 回とも、絵が出始めるのが「接続試行が終わった瞬間」と一致する。**

## Expected

**見ているフォルダの絵は、届かないタブに待たされない。**

## Cause

`ShellImageList` の順番待ちが **1 本の列・1 本のスレッド**。
**先に積まれた届かないパスが終わるまで、後ろは動かない。**

**BUG-041 でタブ帯も同じ列に乗せたので、この形ができた**——
タブ帯の絵は**復元の直後に積まれる**ので、**ほぼ必ず一覧より先**になる。

## Fix（未着手。やり方を決めるところ）

| 案 | 評価 |
|---|---|
| **スレッドを増やす**（2〜4 本） | **解決にならない。**届かないタブが本数ぶんあれば同じこと。メモリ要件にも効く |
| **優先順位を付ける**（手前のペインを先に） | **いま走っている 1 件は追い越せない。**21 秒の待ちは残る |
| ★ **列を 2 本に分ける**（ローカル用・遠隔用） | **UNC かどうかは走る前に分かる**ので判定が確実。遠隔の列が詰まってもローカルは動く。**スレッドは 1 本増える**（要求があったときだけ作る） |
| タイムアウトを付ける | **`SHGetFileInfoW` にタイムアウトは無い** |

**いまは「列を 2 本」が本命**。ただし

- **アイコンの作りを 1 週間で 3 回変えている**（BUG-038 第 1 段 / 第 2 段 / BUG-041）。
  **4 回目を、前回の確認が終わる前に重ねない**
- **割り当てドライブ（`Z:` など）は UNC に見えない。**`GetDriveType` で分けられるが、
  そこまでやるかは決めていない（BUG-044 では同じ判定を入れた）

- 起きるのは**届かないパスのタブを session に持っている人**だけ
