### 追加分（2026-10-06: `Ctrl+A` すべて選択）

| ID | テスト名 | 前提条件 | 手順 | 期待結果 | ステータス |
|----|---------|---------|------|---------|-----------|
| E-20 | ★ **すべて選択** | ファイルとフォルダが混在するフォルダ | 一覧にフォーカスを置いて `Ctrl+A` | **全部が選択される**（ファイルもフォルダも）。選択数が件数と一致 |[ ] |
| E-21 | ★ **フォーカスの枠が動かない** | E-20 の前に 3 行目をクリック | `Ctrl+A` | **枠は 3 行目のまま。**選択だけが全部に付く | [ ] |
| E-22 | ★ **続けてコピーできる** | E-20 のあと | `Ctrl+C` → 別のフォルダで `Ctrl+V` | **全部が貼られる** | [ ] |
| E-23 | ★ **入力欄では文字の選択** | アドレスバーにフォーカス（パスが入っている） | `Ctrl+A` | **パスの文字が全選択される。**一覧の選択は**変わらない** | [ ] |
| E-23a | ★ 名前の変更中も同じ | `F2` で名前の変更を始める | `Ctrl+A` | **編集中の名前が全選択される。**一覧の選択は変わらない | [ ] |
| E-24 | ツリーにフォーカスがあるとき | ツリーをクリックしてから | `Ctrl+A` | **一覧の項目が選択される**（`LVS_SHOWSELALWAYS` で見える）。★ **フォーカスはツリーのまま**。続けて `Ctrl+C` も効く | [ ] |
| E-25 | 0 件のフォルダ | 空のフォルダ／「パスが見つかりません」の板 | `Ctrl+A` | **何も起きない。**落ちない | [ ] |
| E-26 | 「PC」 | 「PC」を開く | `Ctrl+A` → `Ctrl+C` | **選択は付く。**`Ctrl+C` は**何もしない**（今までどおり。ドライブの行で `Delete` が通らないための作り） | [ ] |
| E-27 | ★ 大きいフォルダ | `C:\Windows\System32`（4000 行以上） | `Ctrl+A` | **待たされない**（番号 -1 で 1 回だけ出す作り）。UI の往復・タイムアウト 0 | [ ] |

> **E-23 / E-23a が分かれ目**です。**入力欄では文字、一覧では項目**——
> ここを混ぜると、パスを打ち直そうとして一覧が全選択される（またはその逆）になります。
