# installer 概要

## 目的・背景

いまの配り方は **CI の成果物（zip）を展開して exe を直接置く**だけで、

- **置き場所が人まかせ**——`tmp/bin/win32-<sha>/` に版ごとのフォルダが溜まり、
  **どれが「いまの版」なのか分からなくなっている**（2026-09-23 の確認で、
  9/22 のビルドが 1 日以上起動したままになっていたことが報告された）
- **古い版と新しい版が同時に動く。**`%LOCALAPPDATA%` の `session.json` を共有しているので、
  **後に閉じた方が勝つ**——先に閉じた側の状態が消える
- **消し方が決まっていない。**フォルダを消すだけでは `session.json` が残る
- スタートメニューにもタスクバーにも出ないので、**起動が面倒**

**1 つの exe を置くだけ**のアプリなので、インストーラーがやることは少ない。
**「いまの版が 1 つだけある」という状態を作る**のが主な目的。

## スコープ

### 作るもの

- **Inno Setup のインストーラー**（`ExtendExprorer-setup-<version>.exe`。1 ファイル）
- **ユーザーごとのインストール**（`%LOCALAPPDATA%\Programs\ExtendExprorer`）。UAC は出さない
- **スタートメニューのショートカット**
- **「アプリと機能」に出るアンインストーラー**
- **上書きインストール**（同じ場所に新しい版を入れる。古い版は消える）
- **起動中の検出**——動いているまま上書きすると **exe を置き換えられない**ので、
  閉じるようお願いする
- **バージョン番号**（`csproj` の `<Version>` → exe のファイルバージョン → インストーラー）
- CI に**成果物をもう 1 つ**足す（`ExtendExprorer-setup`）

### 作らないもの

| 作らないもの | 理由 |
|---|---|
| **コード署名** | 証明書を買わないと SmartScreen の警告は消えない。**自己署名では解決しない**（評判を見る仕組みなので）。買うかどうかは別の判断 |
| **MSI / MSIX** | 無人インストールや GPO 配布の予定が無い。MSIX は署名が要るので、いまの配り方では入れられない |
| **PC 全体へのインストール** | 別のユーザーで使う予定が無い。ユーザーごとなら UAC が出ない |
| **自動更新** | 「起動したら新しい版を探す」は、このアプリの**メモリ要件（30MB 前後）**に通信とスケジューラを足すことになる。手で入れ直す |
| **GitHub Release への公開** | **公開リポジトリ**なので、Release に上げると未署名の exe を誰でも落とせる状態になる。CI 成果物のままにする（2026-09-23 の判断） |
| **デスクトップのショートカット（既定で作る）** | **チェックの外れた選択肢として出すだけ**にする。Inno Setup の定型なので足すのは 1 行だが、**既定で作ると消すのが手間**になる |
| **ファイルの関連付け・「〜で開く」メニュー** | エクスプローラーの置き換えは Windows 11 では素直にできない。別の機能エリアの話 |
| **`session.json` の移行** | 置き場所（`%LOCALAPPDATA%`）は変わらないので、移すものが無い |

## 制約

- **ビルドは CI だけ。**手元に .NET SDK も Windows も無いので、
  **インストーラーを作って試すのも CI と、確認をお願いしている方の実機**になる
- **成果物の名前 `ExtendExprorer-win32-x64` は変えない。**
  確認をお願いしている側の道具と、`tmp/確認/old/` の依頼書 20 回ぶんがこの名前を指している。
  **インストーラーは 2 つ目の成果物として足す**
- **配るのは exe 1 本（3.35MB）だけ。**
  `Assets/app.ico` は**実行時に誰も読んでいない**（アイコンは exe に埋まっている
  PE リソースから `LoadImageW(instance, IDI_APPLICATION, …)` で取る）。
  `ExtendExprorer.pdb`（15.4MB）は利用者には不要
- **未署名。**インストーラーと exe の両方で初回に SmartScreen が出る
- **確認が「本当にインストールする」ことになる。**
  これまでの確認はフォルダに置いた exe を起動するだけだったが、
  今回は**レジストリを書き、スタートメニューにファイルを作る。**
  依頼書は**元に戻す手順まで**書く必要がある

## 完了条件

1. CI が `ExtendExprorer-setup-<version>.exe` を成果物として出す
   （`ExtendExprorer-win32-x64` はそのまま残っている）
2. 実機で **入れる → 起動する → 上書きで入れ直す → 消す**が通る
3. **アンインストール後に残骸が無い**——exe・ショートカット・レジストリ（`HKCU`）。
   `session.json` の扱いは spec で決めたとおりになっている
4. **起動したまま上書きしようとしたときに、壊れずに止まる**
5. **いまの版が 1 つだけある状態**が作れている——
   「どのフォルダのどの exe が最新か」を人が覚えなくてよくなっている

## 画面イメージ

```
+------------------------------------------+
|  ExtendExprorer セットアップ             |
+------------------------------------------+
|                                          |
|   ExtendExprorer 0.1.0 をインストール    |
|   します。                               |
|                                          |
|   インストール先:                        |
|   C:\Users\<名前>\AppData\Local\         |
|       Programs\ExtendExprorer            |
|                                          |
|   [ ] デスクトップにショートカットを作る |
|                                          |
|            [ インストール ]  [ 中止 ]    |
+------------------------------------------+

起動中に上書きしようとしたとき:

+------------------------------------------+
|  ExtendExprorer が起動しています。       |
|  閉じてから、もう一度お試しください。    |
|                            [ OK ]        |
+------------------------------------------+
```
