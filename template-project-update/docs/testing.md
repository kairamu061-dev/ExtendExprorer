# テストの線引き

**自動で回るもの**と、**実機で人が確かめるもの**の境目をここに書く。
`agent-rules.md`「Automated Tests」の記録。

> **★ これは実装を始める前に埋めるもの。**
> 「全部 UI だから自動テストは無理」で後回しにしないこと——
> **純粋ロジックは必ずある**（書式の整形・引数の解釈・直列化の往復・
> パスの判定・比較子・木の形）。たいてい数千行あり、
> **そこが黙って壊れる場所**になる。
>
> 記入例: `template_samples/testing.md`
