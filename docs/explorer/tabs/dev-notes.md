## 実装上の判断

<!-- なぜその実装にしたかを記述する -->

| 判断内容 | 理由 |
|----------|------|
| フォルダの中クリックは**裏で開く**・帯の**末尾**に足す（2026-11-23） | 開き方は利用者に確認して決めた（ブラウザと同じく、見ている場所を動かさずに何枚でも開ける）。位置は既存の `PaneModel.AddTab` に合わせて末尾。エクスプローラーの実際の挙動は**確かめていない**（推測で決めていない） |
| 一覧は**一覧の窓そのものを差し替えて**中ボタンを拾う | リストビューは中ボタンでは通知を出さない（`NM_CLICK` / `NM_RCLICK` に当たるものが無い）。列見出しの右クリックと同じ形 |
| 押した行と離した行が**同じときだけ**開く | 押したままずらしたときに、離した先の別フォルダが開くのを防ぐ。タブ帯の中クリック（離したときだけ見る）より 1 段厳しい |
| 一覧の中クリックは**そのペイン**、ツリーは**手前のペイン**に足す | 一覧は押したペインが明らか。ツリーはクリックが手前のペインを動かすので、それに合わせた |
