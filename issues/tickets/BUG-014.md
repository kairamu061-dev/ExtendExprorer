# BUG-014: フォルダツリーのアイコンと文字が縦に潰れる

- **State**: Fixed
- **Reported**: 2026-08-08
- **Area**: folder-tree（`FolderTreePanel.xaml`）

## Summary

左のフォルダツリーで、各行の中身（16px のシェルアイコンと文字）が **約 7px に潰れて**表示される。
アイコンは色の塊が判別できずグレーに見え、フォルダ名は下端が切れる（「ホーム」の「ム」等）。
右のファイル一覧は同じ 19px の行ピッチでも中身 16px を保っており、ツリー側だけの問題。

## Reproduction

1. アプリを起動する
2. 左のフォルダツリーを見る（拡大するとはっきりする）
3. アイコンが潰れてグレーに見え、フォルダ名の下端が切れている

- 実測（UIA）: ツリーの Text 高さ **7px** / Image **16×7**。一覧は Text 16px / Image 16×16
- 実測（画面ピクセル）: ツリーのフォルダ黄色部分の高さ **5px**、一覧は **11px**
- AOT / JIT に依存しないレイアウトの問題

## Expected

一覧と同じく、行ピッチ 19px のままアイコンは 16px、文字は下端が切れずに表示される。

## Cause

`TreeViewItem` に **`Height="19"` を固定していた**（`MinHeight` と併記）。

`TreeViewItem` は `ContentControl` で、テンプレート内に展開シェブロンと `ContentPresenter` を持つ。
外側の高さを固定すると中身がその枠に押し込められ、`Width`/`Height` を 16 で指定したアイコンごと
約 7px に圧縮・クリップされる。`ListViewItem`（一覧）は `MinHeight` だけを与えているので影響がない。

**自分で書いた注意書きに反した変更だった**。同じファイルの 2 行上に

> 行高は file-list の ListViewItem と同じく MinHeight で与える。
> Height を固定すると日本語のフォルダ名が下に見切れる（2026-07-27 報告）

と書いてありながら、2026-08-04 のサイズ調整（`3676a40`）で `Height="19"` を足してしまった。
このときの検証は行ピッチ（19px）だけを見ており、行の中身の高さを測っていなかったため見逃した。

## Fix

`TreeViewItem` の `Height="19"` を削除し、`MinHeight="19"` だけで下限を与える形に戻した
（＝一覧の `ListViewItem` と同じ作り）。注意書きも、なぜ潰れるのかまで書き足した。

- **Fix commit**: 本チケットと同じコミット

## Notes

- 行を詰める変更では、**行ピッチだけでなく行の中身（アイコン・文字）の実効高さも確認する**。
  今回は検証側もピッチだけを見て ✅ としており、2 回続けて見逃している。
- `FontSize="12"` と `Spacing="5"` は今回のサイズ調整の意図どおりなので維持する。
