# win32-migration タスク

## 進め方

**段階ごとに CI ビルド → 実機確認**という現行の運用をそのまま使う。
各段の終わりに**メモリを実測**して、目標 30MB からの乖離を早期に見つける
（最後にまとめて測ると、どの機能が重かったのか分からなくなる）。

現行 WinUI 3 版は**動く状態で残す**。ユーザーが日常的に使っているため、
新実装が同等になるまで置き換えない。
