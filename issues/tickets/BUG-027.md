# BUG-027: コンテキストメニューに「名前の変更」が出ない

- **State**: Fixed（実機での確認待ち）
- **Reported**: 2026-08-30
- **Area**: win32-migration / context-menu / `src/ExtendExprorer.Win32/Services/ShellContextMenuService.cs`

## Summary

ファイル・フォルダのコンテキストメニューに「名前の変更」が出ない。
シェル自身は動詞 `Rena&me` を提供している。

F2 と 2 回目クリックでリネームはできるので、実害は「メニューから呼べない」ことだけ。

## Reproduction

1. ファイルを右クリック
2. 「名前の変更」が無い（「削除」と「プロパティ」の間に入るはずの位置）

## Expected

エクスプローラーと同じく「名前の変更」が出て、選ぶとインライン編集が始まること。

## Cause

`IContextMenu::QueryContextMenu` に **`CMF_CANRENAME`** を渡していなかった。
この印は「この呼び出し元は自分で名前の編集を始められる」という申告で、
渡さない限りシェルは項目を足さない。確認側の見立てのとおり。

## Fix

項目のメニューにだけ `CMF_CANRENAME` を渡す（背景のメニューには不要）。

**実行はシェルに任せない。**シェルに `rename` を実行させても、
一覧の編集を始める手段がこちらに伝わらない。選ばれたコマンドの**動詞**を
`GetCommandString(GCS_VERBW)` で見て、`rename` なら**自前のインライン編集**へ振り替える。

- **Fix commit**: `aaac5c2`

## Notes

動詞に答えないシェル拡張もあるため、取得は失敗を許容する（その場合は従来どおり
シェルへ実行を渡す）。
