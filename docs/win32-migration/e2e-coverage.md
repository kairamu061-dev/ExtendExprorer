# E2E の引き継ぎ表（旧版のテストケース → 新実装）

`docs/explorer/*/test-cases.md` の E2E を、新実装（Win32）で通すための表。

## なぜこの表を作るか

ケースは全部で **約 180 件**ある。**そのまま全部お願いするのは無駄が多い。**
移行は第 0 段から第 5 段まで段階ごとに実機確認してきたので、
**大半はすでに新実装で通っている。**

一方で、**旧版の `[x]` は新実装の合格ではない。**
たとえば `drag-drop` は 16 件すべて `[ ]` / `[~]` だが、
新実装では BUG-029 を含めていちばん厚く確認した領域になっている。
逆に `[x]` が並んでいても、新実装では一度も触っていないものがある。

そこで各ケースを 3 つに分ける。

| 分類 | 意味 |
|---|---|
| **済** | 移行の段階確認で同等の確認が済んでいる |
| **要** | 新実装で狙って確認したことがない。**お願いしたい** |
| **差** | 旧版の実装を書いた文面。**新実装では意味が変わる**ので、先に書き換える |

**迷ったら「要」に倒す。**余計に 1 件試していただく手間は表の 1 行だが、
取りこぼした 1 件は、旧版を捨てたあとに出てくる。
