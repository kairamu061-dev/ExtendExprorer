# BUG-046: インストーラーをダブルクリックした直後に固まった（別の PC）

- **State**: Open（**切り分け待ち**）
- **Reported**: 2026-10-04（利用者）
- **Area**: 切り分け中（`UI/FileListView.cs` / `Services/ShellContextMenuService.cs`、または Windows 側）

## Summary

> インストーラーを他の PC で使おうとしたらダブルクリックした直後にエクスプローラーが固まった

**「エクスプローラー」が、Windows のエクスプローラーなのか ExtendExprorer なのかで、
原因と直し方が別になる。**そこを先に分ける。

## ★ どちらであっても、こちらに 1 つ問題がある

`ShellExecuteExW` を **UI スレッドで同期的に呼んでいる。**

```
UI/FileListView.cs:1289          Activate（ダブルクリック / Enter）
  → Services/ShellContextMenuService.cs:51   ShellExecuteExW（SEE_MASK_INVOKEIDLIST）
```

**同じ呼び出しが 1 分以上返ってこないことを、2026-09-28 の確認で既に測っている**
（H-02。インストーラーに Mark of the Web を付けて実行したとき）。

> **「Run」を押したあと先に進めませんでした。**警告ダイアログは**不可視のまま生き続け**、
> **`ShellExecute` が 1 分以上戻らず**、セットアップのプロセスも起動しませんでした。

**そのとき「アプリ側の話ではないので持ち越さない」と判断した。それが誤り。**
あの観測は「`ShellExecute` は長く返ってこないことがある」という**仕組みの話**で、
**その仕組みを、こちらは UI スレッドで呼んでいる。**

**手前に `SHParseDisplayName` もある**（同じ関数の中）。あちらもシェルを触るので、
届かないパスでは待ちうる。

### これは BUG-043 / BUG-044 と同じ家族の 4 つ目

| | 面 | 状態 |
|---|---|---|
| BUG-038 / BUG-041 | アイコンを引く（一覧・タブ帯） | Fixed |
| BUG-043 | session の復元（起動時） | Fixed |
| BUG-044 | ツリーのノードのクリック | Fixed |
| **BUG-046** | **ファイルを開く（ダブルクリック / Enter）** | **ここ** |

**`grep Directory.Exists` では見つからない。**あちらはパスの確認で、
こちらは**シェルの実行**。**「UI スレッドから呼ぶと待ちうるシェルの関数」**という
括りで数え直す必要があった。

## 切り分け（利用者に確認中）

| 固まったのは | 原因 | 直し方 |
|---|---|---|
| **ExtendExprorer**（この一覧からダブルクリックした） | **こちらの `ShellExecuteExW` が UI スレッド** | 裏へ出す（ただし COM の都合を調べてから。下記） |
| **Windows のエクスプローラー** | **SmartScreen の評判問い合わせ**（未署名＋Mark of the Web）。こちらのコードは 1 行も走っていない | 署名を買う／ブロックの解除／`ExtendExprorer-win32-x64` の exe を直接使う |

**どちらでも上の「こちらの問題」は残る**ので、そこは別に直す。

## 直し方の候補（まだ決めない）

`ShellExecuteExW` を裏のスレッドへ出すのは**自明ではない。**

- `SEE_MASK_INVOKEIDLIST` は**コンテキストメニューのハンドラを呼ぶ**ので、
  **相手が STA の COM オブジェクト**でありうる。MTA の裏スレッドから呼ぶと挙動が変わりうる
- シェルの一部の verb は**メッセージポンプのあるスレッド**を要求する
- `ShellNamespace` / `ShellIcons` の MTA スレッドをそのまま使い回せるかは**調べていない**

**推測で入れない。**（`docs/win32-migration/dev-notes.md`
「推測を 1 往復ぶつけるより、判定材料を 1 往復で採る」）

## 当面の回避

- インストーラーを**右クリック → プロパティ → 「ブロックの解除」**してから実行する
  （Mark of the Web を外すと SmartScreen の問い合わせが起きない）
- または **`ExtendExprorer-win32-x64` の exe を直接置いて使う**（インストーラーを通さない）

## Notes

- **署名していないこと自体は利用者の了解済み**（2026-09-23 の判断）。
  ただし**「警告が出る」と「固まる」は別の話**で、後者は想定していなかった
