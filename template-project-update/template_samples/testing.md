## CI で自動に回すもの（目標環境を要しない）

| 対象 | 守れる退行 | 状態 |
|---|---|---|
| 期限の表示（`DueLabel`） | **今日・明日・期限切れの境目**（日付の境界は off-by-one の巣） | 入れた |
| パスワードの検証規則 | 長さ・使える文字の境目。**規則を緩めたときに気づける** | 入れた |
| タスクの並べ替えの比較子 | 完了済みを下へ・同じ期限のときの決着・降順の対称性 | 入れた |
| JSON の往復（API のリクエスト／レスポンス） | **項目を増やしたときに既存の形が壊れないこと** | 入れた |
| 権限の判定（誰がどのタスクを見られるか） | **他人のタスクが見えないこと。**ここは落ちると事故になる | 入れた |
| 検索のクエリ組み立て | 空文字・記号・前方一致だけの語 | 未 |

## 実機でしか確かめられないもの（手の往復に残す）

**「なぜ自動化しないか」を必ず書く。**書けないなら、それは自動化できる。

| 対象 | なぜ自動化しないか |
|---|---|
| 画面の見た目・崩れ | 文字の幅と折り返しが環境で変わる。**画素で比べる**しかない |
| メール送信（登録・通知） | 外部のサービスに届くかは、受け取る側で見ないと分からない |
| ブラウザ間の差 | 対象のブラウザを実際に動かす必要がある |
| 同時編集 | 2 人が同じタスクを触る状況を、1 プロセスでは作れない |

## 判定に使う道具

**製品自身に数字を言わせる**のが基本。推測の代わりに測定を置く。

| 仕組み | 何を分けるためのものか |
|---|---|
| `?debug=1` のときだけ出す所要時間のログ | 「遅い」ではなく「どの段が何 ms か」 |
| 一覧の件数をレスポンスに入れる | **0 件**なのか**読めなかった**のかを分ける |
| 「起きてはいけない」経路のログ | 鳴らない前提の仕掛け。鳴ったら構造が戻った合図 |
