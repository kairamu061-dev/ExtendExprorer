## 依存関係

- `csproj` の `<Version>` → `.iss`（CI が渡す版数の出どころ）
- `.iss` → `build.yml`（スクリプトが無いと組めない）
- `build.yml` → CI が緑（成果物が出ないと実機で試せない）
- CI が緑 → 確認依頼（**ビルドが無いと確認できない**）

## この機能エリアの特殊なところ

**こちらでは一切試せない。**手元に Windows も .NET SDK も無いので、

- **構文の誤りも CI でしか分からない**（`ISCC.exe` が落ちる）
- **挙動は実機でしか分からない**——入る・起動する・上書きできる・消える・残骸が無い
- **「元に戻す」が今までより重い。**これまでの確認は「exe を置いて起動する」だけだったが、
  今回は**レジストリとスタートメニューに書く。**依頼書に戻し方を全部書く
