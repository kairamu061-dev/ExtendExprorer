# BUG-011: タブにシェルアイコンが表示されない

- **State**: Closed
- **Reported**: 2026-07-30
- **Area**: tabs / shell-icons（`src/ExtendExprorer/Views/PaneView.xaml`）

## Summary

タブ見出しがテキストのみで、フォルダ／ドライブのシェルアイコンが表示されない。
同じシェルアイコンは一覧と左ツリーには表示されている。

## Reproduction

1. アプリを起動する
2. タブ見出しを見る → アイコンが無く、フォルダ名だけが表示される
3. `Windows` フォルダ・`C:\`・日本語名フォルダのいずれのタブでも同様
4. UIA で見るとタブ内に `Image` 要素は存在するが `BoundingRectangle` が ∞（レイアウトされていない）

## Expected

一覧・ツリーと同じシェルアイコン（フォルダは黄色いフォルダ、ドライブルートはドライブのアイコン）が
タブ見出しの左に表示される。

## Cause

`TabViewItem.IconSource` に `ImageIconSource` を使っていた。

```xml
<TabViewItem.IconSource>
    <ImageIconSource ImageSource="{x:Bind Icon, Mode=OneWay}"/>
</TabViewItem.IconSource>
```

`ImageIconSource`（`ImageIcon`）は固有サイズを持たず、`TabViewItem` のアイコン表示部
（`IconSourceElement`）も寸法を与えないため、測定が無限大になりレイアウトされない。
UIA の `BoundingRectangle` が ∞ になっていたのはこの状態。ビルドは通り、例外も出ないため
気づきにくい。

## Fix

`IconSource` を使わず、**一覧・ツリーと同じ構成**（16×16 の `Grid` に、解決までのフォールバック
`FontIcon` と `Image` を重ねる）を `TabViewItem.Header` に直接置いた。寸法を明示するため
レイアウトが確定する。

あわせて `TabViewModel` に `FallbackIconVisibility` を追加し、シェルアイコンが解決するまでは
従来のグリフを表示するようにした（`EntryViewModel` / `FolderNodeViewModel` と同じ方式）。

- **Fix commit**: `2b255a3`
