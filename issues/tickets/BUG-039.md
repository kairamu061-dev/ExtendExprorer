# BUG-039: 「他のタブを閉じる」で、残したタブの履歴と並び順が巻き戻る

- **State**: Fixed
- **Reported**: 2026-09-29（コードレビュー指摘 3）
- **Area**: tabs（`ViewModels/PaneModel.cs`）

## Summary

タブの右クリック →「他のタブを閉じる」を、**いま手前にあるタブに対して**行うと、
そのタブの**履歴と並び順が「最後にそのタブから離れた時点」まで巻き戻る。

## Reproduction

1. タブを 2 枚開く
2. **いったん 2 枚目へ切り替えてから 1 枚目へ戻る**（ここで 1 枚目の控えが確定する）
3. 1 枚目で何度かフォルダを移動して履歴を作り、列ヘッダで並び順も変える
4. 1 枚目を残して「**他のタブを閉じる**」
5. **`Alt+←` が、3 で辿った履歴ではなく古い場所へ飛ぶ。**並び順も 3 の前に戻る

**画面には正しいフォルダが出ている**ので、移動しようとして初めて気づく。

## Expected

残したタブの履歴・並び順が、閉じる直前のまま保たれること。

## Cause

```csharp
var keep = _tabs[index];
_tabs.RemoveAll(t => !ReferenceEquals(t, keep));
ActiveIndex = -1;          // ← ここで手前が消える
Activate(0);               //    Activate 冒頭の ActiveTab?.Let(FileList.SaveTo) が空振りする
```

`Activate` は冒頭で **離れるタブへ現在の状態を書き戻す**作りだが、
その直前に `ActiveIndex = -1` を置いたので `ActiveTab` が null になり、書き戻しが起きない。
続く `FileList.SwitchTo(keep)` は `TabModel` に**保存されている**値を読み直す。

`History` / `HistoryIndex` / `SortColumn` / `SortAscending` を書くのは `SaveTo` だけなので、
**最後に離れた時点の値**が復元される。
**`Path` だけは無事**——`OnFileListStateChanged` が都度写しているため。
だから**画面は正しく、移動して初めて分かる**。

**成立するのは「残すタブが、そのとき手前だった場合」に限られる**
（手前でなかったタブの保存値は正しい）。

**同じ形の正解が隣にある。**`AttachTab` は `ActiveIndex = -1` の**前**に
`ActiveTab?.Let(FileList.SaveTo)` を明示している。

（`CloseTab` / `CloseToTheRight` / `ResetToHome` は、書き戻さない相手が
**捨てられる側**なので問題ない。）

## Fix

`CloseOthers` にも 1 行入れた。

```csharp
ActiveTab?.Let(FileList.SaveTo);   // ★ 先に書き戻す
_tabs.RemoveAll(...);
ActiveIndex = -1;
Activate(0);
```
