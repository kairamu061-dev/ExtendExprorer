# BUG-033: 読めないフォルダで、ペインの背景の右クリックメニューが出ない

- **State**: Open
- **Reported**: 2026-09-07
- **Area**: win32-migration / file-list / `src/ExtendExprorer.Win32/UI/FileListView.cs`

## Summary

読めないフォルダ（`C:\Windows\System32\config` で実測）を開いているペインで、
**背景を右クリックしてもコンテキストメニューが出ない。**

エラーの文字を出す板（`STATIC`）が**ペイン全面を覆っている**ため、
右クリックが板に吸われて一覧まで届かない。

## Reproduction

1. 読めないフォルダへ移動する（一覧が隠れ、「アクセスが拒否されました」の板が出る）
2. ペインの背景（＝板の上）を右クリックする
3. **何も出ない**（同じ窓の、読めるフォルダ側のペインでは出る）

## Expected

少なくとも「更新」「貼り付け」など、フォルダの中身に依らない項目は出したい。

## Cause

`UpdateMessage` がエラー時に一覧（`_hwnd`）を隠し、板（`_message`）を
`bounds` いっぱいに出している。板は `STATIC` なので `WM_CONTEXTMENU` を
親へ回さず、そこで止まる。

## Fix

未着手。
