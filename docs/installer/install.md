## ★★ 入れる前に: **「ブロックの解除」をしてください**

**これを飛ばすと、固まることがあります。**
**固まるのは「ダブルクリックした瞬間」ではなく、警告の「実行」を押したあと**です。

```
setup をダブルクリック
  ↓
「このファイルを実行しますか？ 発行元: 不明」  ← ここは出る
  ↓
「実行」を押す
  ↓
★ ここで固まる。セットアップの画面は出ない
```

**2026-10-04 に別の PC で実際に起きました**（**戻らず、落として再起動**）。
**2026-09-28 の動作確認でも同じ形**が出ています（別の PC）。

```
setup を右クリック
  → プロパティ
  → 全般タブのいちばん下
  → [ ] セキュリティ: このファイルは他のコンピューターから取得したものです。…
         □ 許可する（または「ブロックの解除」）   ← ★ ここにチェック
  → OK
```

**チェックが見えなければ、もう解除されています**（その項目は、必要なときだけ出ます）。

### なぜ固まるのか

ブラウザや GitHub から落としたファイルには **Mark of the Web**（どこから来たかの印）が付きます。
**未署名の exe にこれが付いていると、「実行」を押したあとに Windows の SmartScreen が
「このファイルの評判」を問い合わせ、その応答を待ちます。**

**警告の画面はその前に出る**ので、**「警告は出たから大丈夫」ではありません。**
**止まるのはその次の段**です。

**待てば戻る、とは限りません。**問い合わせ先に届かない環境（回線が無い・塞がれている）では
**無期限に固まりえます**（実際、2026-10-04 の件は戻りませんでした）。

**「ブロックの解除」は、その印を外す操作**です。問い合わせが起きなくなります。

> **`ExtendExprorer-win32-x64` の exe を直接使う場合も同じ**です。
> インストーラーを通さなくても、落としたファイルには同じ印が付きます。

### ★ 他の PC に配るときは、zip のまま渡して「zip を」解除するのが楽です

**zip のブロックを解除してから展開すると、出てきたファイルに印が付きません。**
中身を 1 つずつ解除しなくて済みます。

```
1. zip を右クリック → プロパティ → 「許可する」にチェック → OK
2. そのあと展開する
3. 出てきた exe / setup には印が付いていない
```

**順番が逆だと効きません**（展開してから zip を解除しても、出たファイルの印は消えません）。

## 入れる

**上の「ブロックの解除」を済ませてから、**`ExtendExprorer-setup-0.1.0.exe` をダブルクリックします。

### 「Windows によって PC が保護されました」が出ます

**これは想定どおりです。不具合ではありません。**

```
   Windows によって PC が保護されました
   ...
   [詳細情報]              [実行しない]
```

**「詳細情報」→「実行」**で進んでください。

**ブロックの解除を済ませてあれば、この画面が出ないこともあります。**
出た場合も、**ここは固まりません**（評判の問い合わせは済んでいるか、起きていません）。

**署名していないため**です。**自己署名の証明書を付けても消えません**——
SmartScreen は「どれだけ世の中で実行されたか」を見る仕組みなので、
**消すには有料の証明書（OV / EV）が必要**です。買うかどうかは決めていません。

同じ警告が、**インストールした exe の初回起動でも 1 度だけ**出ることがあります。

### そのあと

- **管理者権限（UAC）は出ません。**自分のユーザーの中だけに入ります
- 入る場所は `C:\Users\<名前>\AppData\Local\Programs\ExtendExprorer`（変えられます）
- **「デスクトップにショートカットを作る」は最初チェックが外れています。**要るなら入れてください
- 最後の「ExtendExprorer を実行する」は**チェックが入っています**

## 入れ直す（新しい版にする）

**同じ手順です。**インストール先は聞かれず、前と同じ場所に上書きされます。
**タブやペインの配置（`session.json`）はそのまま残ります。**

> **★ 先に ExtendExprorer を閉じてください。**
> 起動したままだと、
>
> ```
>    ExtendExprorer が起動しています。
>    閉じてから、もう一度お試しください。
> ```
>
> と出て**何もせずに終わります**（動いている exe は置き換えられないため）。
>
> **別のフォルダから古い版を動かしている場合も止まります。**
> `tmp\bin\win32-<sha>\ExtendExprorer.exe` のような置き方をしていると、
> **インストールしたものと設定ファイルを取り合う**ので、そちらも閉じてください。

## 消す

**設定 → アプリ → インストールされているアプリ → ExtendExprorer → アンインストール**

途中でこう聞かれます。

```
   設定（タブやペインの配置）も削除しますか？
   残しておくと、次に入れ直したときに同じ状態で開きます。

   C:\Users\<名前>\AppData\Local\ExtendExprorer

             [はい]        [いいえ]   ← 既定
```

- **「いいえ」（既定）**——設定を残します。入れ直すと同じ配置で開きます
- **「はい」**——`%LOCALAPPDATA%\ExtendExprorer` ごと消します
  （`session.json` / `session.json.corrupt` / `error.log` / `diag.log`）

**消すときも先にアプリを閉じてください**（起動中は同じメッセージで止まります）。

## どこに何ができるか

| 場所 | 中身 | アンインストールで |
|---|---|---|
| `%LOCALAPPDATA%\Programs\ExtendExprorer\` | `ExtendExprorer.exe` / `unins000.exe` / `unins000.dat` | **消える** |
| スタートメニュー | `Programs\ExtendExprorer\` （**フォルダ**）の中に `ExtendExprorer.lnk` | **フォルダごと消える** |
| デスクトップ（選んだ場合） | `ExtendExprorer.lnk` | **消える** |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\{A11863B4-…}_is1` | 「アプリと機能」の登録 | **消える** |
| `%LOCALAPPDATA%\ExtendExprorer\` | `session.json` ほか | **聞いてから**（既定は残す） |

**レジストリは `HKCU` だけ**です（`HKLM` には何も書きません）。

## よくある質問

**Q. `--diag` を付けたいときは？**
スタートメニューのショートカットのプロパティで、リンク先の末尾に ` --diag` を足すか、
コマンドラインから `"%LOCALAPPDATA%\Programs\ExtendExprorer\ExtendExprorer.exe" --diag` と打ちます。

**Q. インストーラーが 3.5MB しかないけど足りてる？**
足ります。**配るのは exe 1 本（3.55MB）だけ**で、それを圧縮したものです。
`.pdb`（16.3MB）は障害調査用なので入れていません。
`Assets\app.ico` も**実行時に読んでいない**ので入れていません
（アイコンは exe に埋め込まれています）。

**Q. 自動で新しい版に更新されますか？**
**いいえ。**通信とスケジューラを足すとメモリ要件（30MB 前後）に響くので、
入れ直しは手でやる方針です。
