# shortcuts 仕様

## 機能一覧

| # | 機能名 | 説明 |
|---|--------|------|
| 1 | Ctrl+C / Ctrl+X | 選択中の項目（複数可）を CF_HDROP＋Preferred DropEffect(コピー=5/移動=2)でクリップボードへ |
| 2 | Ctrl+V | クリップボードの内容を表示中フォルダへ貼り付け（背景メニューの「貼り付け」と同一処理） |
| 3 | Delete | 選択中の項目をごみ箱へ（シェルの確認・進捗ダイアログ付き） |
| 4 | サイドボタン | XButton1=アクティブタブの「戻る」、XButton2=「進む」。ペイン内クリック位置を問わない |

## 追加分（2026-10-06: `Ctrl+A` すべて選択）

| # | 内容 |
|---|------|
| 1 | **`Ctrl+A` で、いま見ているフォルダの項目をすべて選ぶ**（ファイルもフォルダも） |
| 2 | **文字を打っている間は文字の選択**——アドレスバーと名前の変更の入力欄では、`Ctrl+A` は**その文字をすべて選択**（入力欄にフォーカスがあるかで分かれる。`TryTextEditorKey` が先に拾う） |
| 3 | **フォーカスの枠は動かさない。**選択だけが付く（エクスプローラーと同じ） |
| 4 | **フォーカスを一覧へ奪わない。**ツリーにフォーカスがあるまま押しても選択は付き、`LVS_SHOWSELALWAYS` で見える。続けて `Ctrl+C` も効く（あちらはフォーカスに依らず選択を読む） |
| 5 | **「PC」でも選べる**（ドライブの行）。ただし `Ctrl+C` / `Ctrl+X` / `Delete` は**今までどおり効かない**——「PC」では対象を空で返す作りで、ドライブの行で `Delete` が通る方が困る |
| 6 | 項目が 0 件のとき（空のフォルダ・「パスが見つかりません」の板）は**何も起きない** |

**実装**: `LVM_SETITEMSTATE` を**番号 -1 で 1 回**出す。行ごとに出すと 1 万件のフォルダで 1 万回走る。

## 画面・操作フロー

1. 一覧で項目を選択（Shift/Ctrl の複数選択可） → Ctrl+C / Ctrl+X
2. 任意のフォルダを表示 → Ctrl+V → シェルがコピー/移動を実行（同フォルダコピーは「- コピー」自動リネーム）
3. Delete → ごみ箱へ移動

## 各画面 / 状態の詳細

（既存画面への入力追加のみ。表示の変更なし）

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| 選択なしで Ctrl+C/X/Delete | 何もしない |
| 0 件のフォルダで Ctrl+A | 何もしない |
| 「PC」で Ctrl+A → Ctrl+C | 選択は付くが、コピーは**何もしない**（「PC」は対象を空で返す） |
| クリップボードにファイルが無い状態で Ctrl+V | 何もしない |
| 貼り付け・削除の失敗 | シェルのダイアログに委ねる（アプリは落ちない） |
| 履歴端でサイドボタン | 何もしない（ボタン無効時と同じ） |

## 未対応ケース

- 切り取り中の項目の半透明表示（エクスプローラーの視覚効果）
- Ctrl+Z（元に戻す）— FOF_ALLOWUNDO は付けているためエクスプローラー側からは Undo 可能
