# BUG-040: 2 ペイン以上だと、同じフォルダを読み直してもアイコンの控えが捨てられない

- **State**: Fixed
- **Reported**: 2026-09-29（コードレビュー指摘 2）
- **Area**: shell-icons（`Services/ShellImageList.cs`・`ViewModels/FileListViewModel.cs`）

## Summary

`ShellImageList.BeginFolder` は「**同じフォルダをもう一度読み込んだとき**だけ控えを捨てる」
ために `_folder` と比べていたが、**`_folder` は static の 1 枠**で、
`BeginFolder` は**ペインごとに**呼ばれる。2 ペインで交互に使うと判定が成り立たない。

## Reproduction

1. 2 ペインに分け、A で `C:\X`、B で `C:\Y` を開く（`C:\X` に `.exe` を置いておく）
2. `C:\X\a.exe` を**別の絵を持つ実行ファイルに差し替える**
3. A で `F5`
4. **古いアイコンが残る**

```
A が C:\X を開く          → _folder = "C:\X"
B が C:\Y へ移動          → _folder = "C:\Y"
A で F5（C:\X の再読込）  → _folder("C:\Y") != "C:\X" なので DropFolder が走らない
```

`[icon]` の行も、**別のペインの計測が混ざった内訳**になる。

## Expected

`F5` したペインのフォルダの控えが捨てられ、絵が引き直されること。

## Cause

**再読込かどうかを、static な 1 枠の状態で判定していた。**
正しく知っているのは呼び出し側（`FileListViewModel.Load`）だけ。

## Fix

`BeginFolder(path, isReload)` にして、呼び出し側から渡す。

★ **`_keepSelectionOnReset` を流用しない。**あれは「選択を引き継ぐか」で、
**タブの切り替えは同じパスでも `false`** を渡してくる。
混ぜると**タブを切り替えただけで控えが捨てられる**ので、
`Load` の中で**素のパス比較**を別に取る。

```csharp
var isReload = string.Equals(Path, targetPath, StringComparison.OrdinalIgnoreCase);
_keepSelectionOnReset = keepSelection ?? isReload;
```
