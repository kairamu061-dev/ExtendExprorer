# tabs 仕様

## 機能一覧

| # | 機能名 | 説明 |
|---|--------|------|
| 1 | タブ表示 | ペイン上部にタブを開いた順に表示。タイトルはフォルダ名（ルートはパスそのもの） |
| 2 | タブ切替 | タブクリックでアクティブタブを変更し、一覧・アドレスバーを更新 |
| 3 | タブ複製 | 「＋」ボタンでアクティブタブと同じパスの新規タブをアクティブタブの右隣に追加しアクティブ化。履歴は引き継がない |
| 4 | タブクローズ | **ホイールクリック**、またはタブ上の**右クリックメニュー**で閉じる（「×」ボタンは廃止・2026-08-09 変更）。アクティブタブを閉じたら右隣（なければ左隣）をアクティブ化 |
| 5 | 最終タブの扱い | ペインの最後のタブを閉じたらペインを閉じる。最後のペインの場合はホームのタブを開き直す |
| 6 | **折り返し表示** | タブ帯の幅に収まらなくなったら**2 列目以降へ折り返す**（横スクロールしない）。帯の高さは行数に応じて伸びる |
| 7 | **幅は名前に合わせる** | タブ幅はフォルダ名の長さに合わせる（下限・上限あり）。全タブ同じ幅にはしない |

| **アイコン**（2026-09-18 追加） | タブ見出しの**左にフォルダアイコン**を出す。**実パスで引く**ので、ダウンロードのように固有の絵を持つフォルダはその絵になる。「PC」はパスが無いので解析名から PIDL を作って引く。アイコン番号は**並べるときの 1 回だけ**引く（描くたびに引くと、無効化のたびにシェルを呼ぶ） |
| **ホバー**（2026-09-18 変更） | `#E5F1FB` → **`#CCE8FF`** に濃くし、**枠（`#99D1FF`）**を足した。色を濃くするだけより、枠を足す方が「押せる」ことがはっきりする。ペインの帯のボタン・パンくずと同じ色にそろえてある |

## 画面・操作フロー

1. タブをクリック → `activeTabId` 変更 → ファイル一覧・アドレスバーが再描画
2. 「＋」をクリック → 新規 Tab（path = アクティブタブの path）を挿入しアクティブ化
3. タブをホイールクリック、または右クリック →「タブを閉じる」→ 仕様 4 / 5 に従いアクティブタブ・ペインを調整

## 各画面 / 状態の詳細

### タブバー

- **表示内容**: 各タブ（アイコン＋タイトル）と、最後のタブの直後に続く「＋」ボタン。
  タブ幅は名前に合わせ、**下限 60px / 上限 240px**（超過分は省略記号）
- **折り返し**: 帯の幅に入らないタブは次の行へ送る。**行数に応じて帯の高さが変わる**
- **アクティブタブ**: 背景 #FFFFFF・下線 #0078D4 で強調し、さらに**他のタブより 3px 高く描く**
  （行の下端を揃え、アクティブだけ上に伸ばす）
- **ホバー**: マウスが乗ったタブは背景 #E5F1FB
- **操作**: クリック（切替）、ホイールクリック（クローズ）、右クリック（コンテキストメニュー）、＋（複製）
- **遷移先**: なし（ペイン内で完結）

### タブの右クリックメニュー

| 項目 | 動作 |
|------|------|
| タブを閉じる | そのタブを閉じる（仕様 4 / 5 に従う） |
| 他のタブを閉じる | そのタブ以外をすべて閉じる |

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| タブ数が上限（50）に達した状態で「＋」 | 何もしない（ボタン無効化） |

## 未対応ケース

- タブの並べ替え（ドラッグ）— **第 2 段で対応**
- タブのペイン間移動（ドラッグ）— **第 3 段で対応**
- Ctrl+T / Ctrl+W 等のキーボードショートカット（将来対応）

## 追加分（2026-09-21: ドラッグ中の影）

| # | 内容 |
|---|------|
| 1 | タブをドラッグしている間、**掴んだタブの絵が半透明でカーソルに追従する**。見た目は**タブそのまま**（アイコン＋名前＋枠・実寸）。掴んだ場所が同じ位置でカーソルに付いてくる |
| 2 | **落ちる位置を示す縦線は残す。**影は「何を持っているか」、線は「どこに入るか」で役割が違う |
| 3 | 影は**別のペインの帯の上でも見える**（最上位の窓なので）。帯の中に描く方式だと、ペインをまたいだ瞬間に消える |
| 4 | 影は**当たり判定の対象にしない**（`WS_EX_TRANSPARENT`）。あわせて帯の探し方も、重なり順に頼らず**矩形で引く**形にした |
| 5 | ドラッグが終わる道すべて（確定・取り消し・キャプチャの取り上げ・帯の破棄）で消す |
| 6 | **影には持ち主（主窓）を付ける。**持ち主のいない最上位の窓は `Process.MainWindowHandle` が主窓だと思い込み、**ドラッグ中だけ外から見た「アプリの窓」が変わる**。持ち主を付ければ列挙から外れ、ついでに持ち主と一緒に壊れる |
| 7 | 透け具合は `SourceConstantAlpha = 180`。**白地でも灰地でも読める**ことを実測で確認済み（文字の輝度 75・アイコンの彩度は素の約 7 割） |
