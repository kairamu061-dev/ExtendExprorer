# installer 仕様

## 機能一覧

| # | 機能名 | 説明 |
|---|--------|------|
| 1 | **インストール** | `%LOCALAPPDATA%\Programs\ExtendExprorer\ExtendExprorer.exe` に置く。**UAC は出さない**（ユーザーごと） |
| 2 | **スタートメニュー** | 「ExtendExprorer」を作る。ここから起動できる |
| 3 | **デスクトップのショートカット** | **チェックの外れた選択肢**として出す。既定では作らない |
| 4 | **アンインストール** | 「アプリと機能」に「ExtendExprorer」として出る。exe・ショートカット・レジストリを消す |
| 5 | **上書きインストール** | 同じ場所に新しい版を入れる。**古い版は残らない**（ファイルが 1 つなので置き換えるだけ） |
| 6 | **起動中の検出** | 動いているまま入れようとしたら**止めて知らせる**。exe を置き換えられないため |
| 7 | **バージョン番号** | `csproj` の `<Version>` が **exe のファイルバージョン**と**インストーラーのバージョン**の両方になる |
| 8 | **インストール後に起動** | **チェックの入った選択肢**として出す（最後の画面） |

## 画面・操作フロー

### 初めて入れるとき

1. `ExtendExprorer-setup-0.1.0.exe` をダブルクリック
2. **SmartScreen の警告**（未署名のため）→「詳細情報」→「実行」
3. インストール先の確認（`%LOCALAPPDATA%\Programs\ExtendExprorer`）と
   「デスクトップにショートカットを作る」（**チェック外れ**）
4. 「インストール」→ 数秒で完了
5. 「ExtendExprorer を実行する」（**チェック入り**）→「完了」

### 入れ直すとき（新しい版）

1. 同じ手順。**インストール先を聞かずに、前と同じ場所へ入れる**
2. **起動していたら 2 の前で止まる**（下記「エラーケース」）

### 消すとき

1. 「設定 → アプリ → インストールされているアプリ」から「ExtendExprorer」→ アンインストール
2. **`session.json` を消すか聞く**（下記）
3. 完了

## 各画面 / 状態の詳細

### インストール先の画面

- **表示内容**: インストール先のパス（**変更できる**）、
  「デスクトップにショートカットを作る」（チェック外れ）
- **操作**: 「インストール」/「中止」
- **遷移先**: 進行画面 → 完了画面

### 完了画面

- **表示内容**: 「ExtendExprorer を実行する」（**チェック入り**）
- **操作**: 「完了」
- **遷移先**: なし（チェックが入っていれば、そのまま起動する）

### アンインストール時の確認

- **表示内容**:
  「**設定（タブやペインの配置）も削除しますか？**
  残しておくと、次に入れ直したときに同じ状態で開きます。」
- **操作**: 「はい」（`%LOCALAPPDATA%\ExtendExprorer` を消す）/「いいえ」（**既定**。残す）
- **遷移先**: なし

> **既定は「残す」。**入れ直しのときに消えると困る方が痛い。
> 消したい人は消せる、という形にする。

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| **ExtendExprorer が起動している** | 「**ExtendExprorer が起動しています。閉じてから、もう一度お試しください。**」→ **何もせずに終わる。**閉じて再実行すれば入る |
| **未署名のため SmartScreen が出る** | インストーラー側では対処しない。**README に「詳細情報 → 実行」と書く** |
| 32bit の Windows で実行した | 「このアプリは 64bit の Windows が必要です」→ 終わる（`ArchitecturesAllowed=x64compatible`） |
| インストール先に書けない（容量・権限） | Inno Setup の既定のエラー表示のまま。**特別な扱いはしない** |
| **同じ版をもう一度入れた** | **止めない。**そのまま上書きする（壊れたファイルの入れ直しに使えるので） |
| **新しい版が入っているところに古い版を入れた** | **止めない。**そのまま上書きする（版を戻す手段として残す） |

> **「同じ版・古い版を止めない」のは意図。**止める作りにすると、
> **壊れたときの入れ直しと、版を戻す操作の両方ができなくなる。**
> どちらも「いまの版が 1 つだけある」という目的には反しない。

## 未対応ケース

- **コード署名**——証明書を買うかどうかを決めてから
- **自動更新**——メモリ要件に通信とスケジューラを足すことになる
- **MSI / MSIX**——無人インストールや GPO 配布の予定が無い
- **PC 全体へのインストール**——別のユーザーで使う予定が無い
- **ファイルの関連付け・右クリックメニューへの追加**——別の機能エリアの話
- **GitHub Release への公開**——公開リポジトリなので、未署名の exe を誰でも落とせる状態になる
- **32bit / ARM64 版**——本体が `win-x64` のみ
